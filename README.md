# 习惯打卡

一个零依赖的每日习惯打卡网页。界面采用黑、深紫与绯红配色，点击习惯卡片即可完成或取消当天打卡。

## 功能

- 首次打开预置健身、羽毛球、篮球、吉他、跳舞、学习编程六项习惯
- 添加、重命名和删除习惯
- 实时显示今日完成数与进度
- 按设备本地日期自动重置每日打卡状态
- 使用浏览器 Local Storage 保存数据
- 适配手机和电脑，支持键盘操作与减少动态效果设置

## 使用

直接用浏览器打开 `index.html` 即可。

如果需要在手机或其他设备访问，可以把目录部署到任意静态网站托管服务。

## 数据说明

习惯名称和当天完成状态仅保存在当前浏览器的 Local Storage 中，不会上传到服务器。清除浏览器数据后，记录会丢失。

## 文件

- `index.html`：页面结构
- `styles.css`：视觉样式与响应式布局
- `app.js`：打卡、习惯管理和本地存储逻辑
